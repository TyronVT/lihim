# Lihim brand assets

Everything shipped under `apps/web` for the brand is generated by one script from
`design/source/icons.png`. Don't edit the exported files by hand. Change the script
or the source, then regenerate.

```sh
python3 -I design/scripts/export_assets.py
```

It needs Python 3 with Pillow (WebP + FreeType) and numpy, and no network. It
overwrites every output listed below and prints their sizes. Running it twice
gives identical files.

## Sources

| Path | What it is |
|---|---|
| `source/icons.png` | 1254×1254 illustrated sheet, 2×2 grid: Mark (TL), Verified (TR), Poll (BL), Group (BR). Near-black grain bg ≈ `#0A0B0D`. |
| `source/glyph-mono.svg` | Monochrome Glyph (white, evenodd: face void cut out, eyes kept). Generated. |
| `scripts/export_assets.py` | All exports. Also holds the Glyph geometry as cubic Béziers in a 64×64 grid. |
| `fonts/Geist-SemiBold.ttf`, `fonts/Geist-Regular.ttf` | Used for the OG wordmark and tagline. From the `geist@1.8.2` npm package (vercel/geist-font), SIL OFL 1.1, see `fonts/OFL-Geist.txt`. |

## How the exports are made

- **Figure extraction.** Each figure is cut from its measured bbox. The background
  is removed by a flood fill from the crop edges only. That keeps enclosed dark
  shapes opaque: the face void, the star, the ballot slot. The anti-aliased rim
  is un-mixed against the known bg colour, which removes the dark halo on light
  tiles. Then the alpha gets a 0.5 px feather. Group uses a higher flood ceiling
  (24 instead of 18) to catch the faint contact shadows between heads and bodies.
- **Illustrations** share one scale: the tallest figure (Mark) fills 90% of the
  tile, so the four keep their relative sizes from the sheet. At @3x the Mark is
  upscaled about 1.17× from the source (369 px tall → 432 px). If a higher-res
  master exists, swap it into `source/` and update `FIGURES` in the script.
- **Glyph** was traced from the Mark's outline (row extents sampled from the sheet)
  and then simplified so it holds up at 16 px. It is symmetric. The face void is
  about 10% narrower and its tip is lifted, so the hood rim and cape survive. The
  eyes are about 1.25× larger and tilted 8° instead of the illustration's ~25°, so
  they read calm and not sinister. The SVG and the Pillow rasters come from the
  same Bézier data. An rsvg-convert render of the SVG matches the Pillow badge to
  0.5/255 mean alpha difference.

## Using them in the app

- Next.js picks up `app/icon.svg`, `app/favicon.ico` and `app/apple-icon.png` by
  file convention. Don't also add `<link rel="icon">` tags.
- `app/manifest.ts` icon entries are in `lihim-DESIGN.md` → Export checklist.
- Illustrations: `next/image` with `width={160} height={160}`. Use the `@2x` file
  as `src` (or `@3x` via a custom loader / `srcSet`). In light theme, set them on
  an `--ink-950` tile; they are drawn for dark.
- Grain: `body::before { background: url(/grain.png); opacity: .03; pointer-events: none; }`,
  dark theme only.

## Before launch

- Test `maskable-512.png` at maskable.app.
- Pilot check from the design spec: show the Mark to advisers/officers. If
  "hacking" comes up, soften the hood and eyes in the source, then regenerate.
